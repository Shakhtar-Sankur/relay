# scripts/chaos.py: a real cluster (relay-worker processes + the Swift API server) serving SmolLM2-135M on the CPU
# backend, run twice per configuration on a fresh cluster each time: without faults, then while workers are
# SIGKILLed at random and restarted in place. Every output of the chaos run must equal the fault-free run's.
# Machine: 4 CPU cores. Sampled (temperature 0.8, a fixed seed per request), streaming, 8 requests at a time.

$ python scripts/chaos.py --model models/smollm2-135m --prefill 2 --decode 2 --requests 64 --kills 10 --concurrency 8 --max-tokens 48 --seed 0

fault-free run: 47.7 s
chaos run:      58.0 s, 10 workers killed with SIGKILL and restarted (3 decode, 7 prefill)
identical outputs: 64 of 64; failed requests: 0
